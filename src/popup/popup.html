Globemallow

How to run an audit
Steps
  1. Open the website you want to audit.
  2. Open DevTools:
    Ctrl + Shift + I (Windows/Linux)
    ⌘ + ⌥ + I (Mac)
    Or right click → Inspect.
  3. Open the Globemallow tab in DevTools.
    If it’s hidden, click the » overflow menu.
  4. Click Analyze and wait for results.
  5. Click any metric to read an explanation.
Tip: Pin the extension to the toolbar so this popup is always one click away.
